# Contributing

Create a virtual environment, install `.[dev]`, make focused changes, and run `make quality` before opening a pull request.

Reusable ML logic belongs in `src/ml_unsupervised/`. Notebooks should demonstrate or analyze package behavior rather than introduce a second implementation.

New algorithms should include tests, documented parameter/inference behavior, and a clear reason for inclusion.
